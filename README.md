# Uncanny Clicker

Uncanny Clickerは、Windows向けの日本語自動クリックアプリです。Pythonのインストールやコマンド入力は不要です。アカウント登録は必要なく、インターネットに接続せずに使えます。

[ダウンロード（GitHub Releases）](https://github.com/Rbronze4/Uncanny-clicker/releases) · [不具合を報告](https://github.com/Rbronze4/Uncanny-clicker/issues)

## できること

- マウスで選んだ位置、または入力した座標を繰り返し左クリック
- 1秒に1〜50回の速度調整
- 回数指定（1〜1,000,000回）または停止するまでの繰り返し
- 開始前の3秒カウントダウン、進捗と実行結果の表示
- ショートカットキーの変更と設定保存
- 停止ボタン、停止キー、画面の角へのマウス移動による停止

## 動作環境

Windows 10（バージョン1703以降）またはWindows 11の64ビット環境が対象です。
管理者権限やインストーラーは必要ありません。

## ダウンロード・起動

1. [Releasesページ](https://github.com/Rbronze4/Uncanny-clicker/releases)を開きます。
2. リリースの「Assets」から `UncannyClicker-v1.0.0-win64.zip` をダウンロードします。
3. ZIPを右クリックし、「すべて展開」を選びます。
4. 展開先の `UncannyClicker` フォルダにある `UncannyClicker.exe` を開きます。

**exeだけを取り出さず、同じフォルダのファイルをまとめて保管してください。**
Releasesに配布ZIPが表示されていない場合は、まだ公開されていません。

## はじめて使うとき

まずは誤操作しても問題のない画面で、少ない回数から試してください。

1. **場所を選ぶ** — 「マウス位置を取得」を押し、クリックしたい場所へカーソルを移動して **F6** を押します。X・Y欄へ数値を入力することもできます。
2. **速度を決める** — スライダーで調整します。「16 CPS」は1秒に16回という意味です。
3. **回数を決める** — クリック回数を入力します。繰り返し続けたい場合は「停止するまで繰り返す（無制限）」をオンにします。
4. **開始する** — 対象の画面を前面にして **F9** を押します。「開始」ボタンでも実行できます。3秒後にクリックが始まります。
5. **停止する** — 途中で止めたいときは **F8** または「停止」を使います。回数指定の場合は自動で終了します。

キーは初期設定です。変更後は画面に表示されているキーを使用してください。

## ショートカットキーを変更する

メイン画面下部の **「設定（ショートカットキー）」** を開き、変更したいキーを入力して **「保存して適用」** を押します。画面に見えない場合は下へスクロールしてください。

|操作|初期設定|
|---|---|
|マウス位置を確定|F6|
|クリックを開始|F9|
|クリックを停止|F8|
|位置取得をキャンセル|Esc|

`F7`、`Ctrl+Shift+A`、`Alt+Q` のように指定できます。Ctrl・Alt・Shift・Winと、英数字、Fキー、方向キー、Space、Enter、Tab、Home、End、PageUp、PageDown、Insert、Delete、Backspace、Esc、テンキー（Num0〜Num9）を組み合わせられます。

- 同じ組み合わせを複数の操作に割り当てることはできません。
- F12や一部のWindows用キー、他のアプリが使用中の組み合わせは使えません。
- 登録や保存に失敗すると変更を取り消し、変更前のキーへ戻します。画面の案内を確認して別のキーを指定してください。
- 「初期値に戻す」を押してから保存すると、上の表のキーに戻せます。
- 実行中や位置取得中は変更できません。設定画面を開いている間もクリックを開始できません。
- 開始・停止・位置確定キーは、別のアプリを操作中でも有効です。位置取得の取消キーは取得中のみ有効です。

文字キーだけを設定すると通常の文字入力と重なりやすいため、修飾キーとの組み合わせをおすすめします。

## 安全に止めるには

**停止キー（初期設定：F8）** を押すか、マウスをいずれかのディスプレイの角へ移動してください。「停止」ボタンでも止められます。開始前のカウントダウン中も停止できます。

画面の角は緊急停止用のため、クリック先には指定できません。停止キーやマウス監視を利用できないときは、警告を表示して開始を無効にします。

クリック先は固定座標です。その場所に別のウィンドウが重なると、別のウィンドウをクリックします。実行中は画面やウィンドウの切り替えに注意してください。

## 設定と実行結果

位置・速度・回数・無制限モードは終了時に、ショートカットキーは「保存して適用」時に保存します。次回起動時に復元されます。保存先は `%APPDATA%\UncannyClicker\config.json` です。

終了後はクリック回数、実行時間、平均速度、終了理由を表示します。回数はWindowsへクリックを送信できた回数です。対象アプリ側で処理された回数と一致しない場合があります。

## 困ったとき

|症状|確認すること|
|---|---|
|起動できない|ZIPをすべて展開したか、exeと同じ場所に `_internal` フォルダがあるか確認してください。|
|キーが反応しない|画面に表示されているキー、Fnキーの必要性、他アプリとの競合を確認してください。設定画面で別のキーに変更できます。|
|開始ボタンを押せない|画面の警告を確認してください。設定画面や位置取得モードを閉じてください。別のUncanny Clickerが起動している場合は終了してから再起動してください。|
|クリック位置が違う|位置を取得し直してください。ディスプレイ構成を変えた後も再取得してください。|
|クリックが届かない|対象の画面を前面にしてください。管理者権限のアプリやロック画面などは操作できない場合があります。|
|設定した速度にならない|Windowsや対象アプリの負荷により変動します。速度を下げて試してください。|
|設定が初期値に戻った|設定ファイルを読み込めない場合は初期値で起動します。画面の警告を確認してください。|
|画面下の項目が見えない|ウィンドウ内を下へスクロールしてください。|

未署名のexeではSmartScreenやセキュリティ製品の警告が出る場合があります。配布元を確認し、セキュリティ機能を無効化しないでください。

## 利用上の注意

- 対象アプリやサービスの利用規約を守ってください。
- ゲームの保護機能やCAPTCHAを回避する機能はありません。
- 通信、利用履歴の外部送信、自動更新は行いません。
- 複数画面・負の座標に対応する実装ですが、すべての画面配置や拡大率での動作確認は完了していません。
- Windowsやアプリ全体が応答しない場合など、すべての状況で停止を保証するものではありません。
